# 🎨 Color Changer

A simple and interactive Color Changer web application built using HTML, CSS, and JavaScript. Users can change the page background to predefined colors or generate random colors with a single click.

## ✨ Features

- 🔴 Change background to Red
- 🟢 Change background to Green
- 🔵 Change background to Blue
- 🌈 Generate random hexadecimal colors
- 🔄 Reset the background to its default color
- 🖥️ Display the current HEX color code
- 📱 Responsive layout for smaller screens

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — DOM manipulation, event listeners, reusable functions, and random color generation

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
